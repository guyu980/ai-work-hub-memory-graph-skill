# Public Interviews And Discovery

Use for public podcasts, interviews, talks and substantive public conversations. The goal is useful changes in understanding, not a media-monitoring archive.

## Entry And Configuration

- A user-supplied source goes directly through non-project source analysis. A company-owned diligence interview still belongs to Diligence.
- Discover proactively only within an authorized task. Prefer integrating with existing intelligence reports; adding a schedule, destination or paid service needs corresponding authorization.
- Read the task's private configuration if provided. A suggested location is `<workspace_root>/Memory Graph/config/公开内容关注.md`; another location is valid. Keep useful channels and official links, high-signal people or aliases, and optional priority questions there. People and channels are starting points, not a whitelist or a roster to exhaust every run.
- If configuration is absent, use the task's scope and relevant existing knowledge. Do not block normal analysis or invent a mandatory setup process. Watchlist membership does not require a people card.

## Discover And Select

1. Combine three paths: important people's appearances across channels; questions from relevant sectors, technical themes and priority projects; a small set of trusted channels. Use existing indexes and targeted notes, not a full workspace read. Expand beyond familiar names and themes when a promising source appears.
2. Reuse official episode pages, feeds, video channels and the report's normal searches. Prefer stable official links; do not invent feed URLs. Use public names and topics in web queries, not private customer details, unpublished valuations or internal project conclusions.
3. In daily intelligence, discover alongside ordinary news and analyze timely, important sources in the same run. In weekly intelligence, explicitly review the reporting window for substantive conversations missed by daily coverage. Cadence belongs to the task, not this skill; neither path requires a daily full-person or full-channel sweep.
4. Screen title, guest, description and chapters first. Read further when the source offers a useful mechanism, operating experience, a changed view, a meaningful counterargument or a new direction worth understanding. A famous guest, promotional claim or repeated talking point alone is insufficient. Do not impose item quotas or fill empty sections.
5. Check recent report coverage and source notes before intake. Match the original episode URL or video ID plus guest, topic and date; platform titles and publication dates can differ. Preserve alternate links in the same source folder. New conversations get new source notes; reprocessing the same conversation improves its existing note.
6. Once a source qualifies, read and analyze it within the authorized run rather than stopping at a candidate list for user approval. Materiality controls depth. If access or execution limits prevent completion, preserve the concrete unfinished step in the task's existing run record without creating a new review queue or calling the source analyzed.

## Read And Analyze

- Prefer the publisher's full transcript or original written interview, then official subtitles and available original audio/video where supported. A useful third-party full transcript is acceptable if identified as such. Do not endlessly retry unavailable subtitles, bypass access controls, or add paid transcription without authorization.
- Preserve the original link and obtainable transcript/parsed text under the existing source layout. Record publication date, speaker, transcript provenance and meaningful coverage limits. If only chapters, summaries or excerpts are accessible, say exactly that; do not present a full interview analysis or invent missing statements. Revisit access only when a concrete alternative or worthwhile unfinished step exists.
- Read the full available conversation for substantive analysis. Targeted reading is acceptable when the question is narrow, but identify the sections actually used. Distinguish the speaker's view, disclosed experience, externally supported facts and the agent's inference without a claim-by-claim evidence ledger.
- Calibrate only consequential ambiguities, numbers or technical terms using the original or a relevant primary source. Do not turn an interview into an audit, benchmark reproduction or formal research report.
- Retrieve relevant prior knowledge and explain the important mechanisms, strongest competing interpretation, and what is reinforced, revised or contradicted. Where useful, connect to projects, valuation assumptions or practical follow-up. Familiar themes are not the only valid destination; genuinely new understanding can justify a new theme.

## Persist And Report

- Reuse `知识来源/主题资料/YYYY/YYYY-MM-DD_来源主体_主题/` for public conversations by default. Honor an existing source's location instead of making a duplicate. Maintain one substantive `核心整理.md` per source; do not create a second podcast library or candidate database.
- When used in a report, finish the selected source note first, cite its useful findings in the report, then archive the report before the consolidated graph writeback. Record incomplete writeback in the existing run record so a resumed run reuses the source note.
- A weekly report may include an optional public-perspectives section: speaker/topic, new understanding, implications for existing views, and a link to the full note and original source. Group related conversations to show convergence or disagreement, not to repeat separate summaries. Omit the section when nothing merits inclusion. In externally delivered reports, retain usable original-source links; never upload private notes or disclose private project context to new recipients without authorization.
- Update the current understanding in the most direct existing sector, technical, valuation or project object, linking to the source note. A source note may remain useful without a graph delta. Do not create an event for every interview or a person card for every guest.
- Project implications from automation belong in sourced `外部动态`; they can suggest reassessment but never silently change formal decisions, status, participation, position, price views or confidence. Rebuild and validate once after actual graph changes, not after discovery alone.
